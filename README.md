# DRAFTS

## Resumo

Repositórios de rascunhos. Rascunhos representam ideias com alguma estrutura. Rascunhos servem de base para a criação de outros artefatos, como ADRs ou páginas de handbook.

## Estrutura

Os rascunhos são organizados como arquivos Markdown na raiz do repositório, usando a extensão `.md`.

Por exemplo:

```plaintext
drafts/
  inner-loop.md
```
