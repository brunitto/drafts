# PROTOTYPE

## Resumo

Usar protótipos vivos e de alta fidelidade para alinhar a comunicação e validar hipóteses.

Este rascunho está contextualizado com o uso de agentes de IA na criação de protótipos.

## Proposta

Escolher as principais funcionalidades (ignorar sign up, sign in, sign out).

Usar implementações simples (entidades, casos de uso).

Usar persistência simples (arquivos serializados como JSON).
